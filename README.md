**SHADOWLINE — Night Infiltration.** A top-down stealth game in three levels: slip past
patrolling guards with wall-clipped vision cones, hide in bushes, duck behind crates,
throw coins to pull guards off their routes, steal the intel and reach the exit unseen.
Guards patrol, grow suspicious, investigate noises, chase and search; running is fast
and loud. Original art, code and synthesized sound — no assets, no network requests.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

WASD / arrows to move, Shift to run, click to throw a distraction coin, P to pause,
M to mute. `?shot=start|play|close|end&seed=1` stages the four screenshot scenes.
